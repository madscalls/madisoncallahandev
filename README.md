# madisoncallahandev

Madi Callahan's portfolio: a playful intro, her projects, and a little mini golf game called Roll it in.

- Live: https://madscalls.github.io/madisoncallahandev
- Built with React, Vite and GSAP

## Run it

```bash
npm install
cp .env.example .env
npm run dev
```

Paste your Web3Forms access key into `.env` first.

## Deploy

```bash
npm run deploy
```

This checks that the code has no comments, builds the site, and publishes it to the `gh-pages` branch.

Coding agents: read `AGENTS.md` first.
